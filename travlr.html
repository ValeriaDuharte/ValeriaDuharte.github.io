ARTIFACT OVERVIEW

About the Project

Travlr Getaways is a full-stack web application developed during my Computer Science coursework. The project uses Angular for the frontend, Node.js and Express for the backend, and MongoDB for data storage.

The application allows travel information to be stored, retrieved, and displayed through communication between the user interface, backend API, and database.

I selected Travlr for my CS499 ePortfolio because it demonstrates several areas of software development that are important to my professional growth. The project provided an opportunity to analyze an existing application, troubleshoot problems across multiple layers of the application, and implement enhancements that improved its functionality and reliability.

ENHANCEMENT ONE

Software Design & Engineering

The first major enhancement focused on improving the software engineering aspects of the Travlr application. Because the project contained multiple connected components, I first analyzed the existing structure and identified problems that affected the application's reliability and maintainability.

I worked through issues involving the Angular frontend, Node.js and Express backend, API communication, and MongoDB connectivity. Troubleshooting these problems required me to trace how information moved through the application rather than treating individual components as isolated pieces of code.

The enhancement process strengthened the application's reliability and helped me develop a better understanding of full-stack software architecture.

ENHANCEMENT TWO

Database Development

The second enhancement focused on the database component of the application. Travlr uses MongoDB to store travel information, making the database an important part of the application's functionality.

I worked on database integration, data retrieval, CRUD functionality, validation, and error handling. I also verified communication between MongoDB, the Express API, and the Angular frontend.

This enhancement demonstrated my ability to work with a NoSQL database as part of a full-stack application rather than treating the database as an isolated component.

ARTIFACT NARRATIVE

Learning and Reflection

The Travlr enhancement taught me that working with an existing application requires a different mindset than creating a project from the beginning. Before changing anything, I needed to understand how the existing components interacted and determine where problems were occurring.

One of the biggest challenges was troubleshooting issues across the frontend, backend, and database. Problems such as server connectivity, API communication, and database availability demonstrated how a failure in one component can affect the entire application.

Working through these issues strengthened my debugging skills and gave me more confidence working with full-stack applications.

The enhancement also reinforced the importance of testing changes instead of assuming that a modification worked simply because the application compiled. I learned to verify functionality at multiple points in the application and use errors as information that could help identify where a problem originated.

Overall, Travlr demonstrates my growth in software design and engineering and database development and provides evidence of my ability to analyze, modify, test, and improve an existing software system.
