ARTIFACT OVERVIEW

About the Project

TreasureMaze is an artificial intelligence project in which I developed an intelligent agent for a treasure hunt game. The agent represents a pirate NPC whose goal is to navigate a maze, locate the treasure, and reach the goal before the treasure can be found by another agent.

The project required me to apply algorithms and data structures to an AI problem rather than simply writing code that followed a fixed sequence of instructions. The pirate agent needed to learn which actions were more effective by interacting with its environment and receiving rewards based on its decisions.

I selected this artifact for my CS499 ePortfolio because it demonstrates my ability to apply computer science concepts involving algorithms, data structures, machine learning, and problem solving to a practical application.

ALGORITHM ENHANCEMENT

Reinforcement Learning

The primary algorithmic enhancement involved reinforcement learning. The pirate agent learned through repeated interactions with the maze rather than being given a predetermined path to the treasure.

The agent evaluates the current state of the environment, selects an available action, receives a reward or penalty, and uses that experience to improve future decisions. Over repeated training episodes, the agent can learn which actions are more likely to lead toward the goal.

I worked with Q-learning and deep Q-learning concepts to train the agent. These approaches use the relationship between states, actions, and rewards to improve the agent's decision-making over time.

DATA STRUCTURES

Representing States and Actions

Data structures were important to the way the agent represented information about the environment. The agent needed a way to keep track of states, possible actions, rewards, and learned values while it interacted with the maze.

The training process also required storing experiences and using previously collected information to improve future decisions. Organizing this information allowed the learning algorithm to repeatedly evaluate past experiences instead of treating every decision as completely new.

Working with these structures helped me understand that data structures are closely connected to algorithm performance. The way information is stored and accessed affects how effectively an algorithm can process it.

TRAINING & TESTING

Training the Agent

Training the pirate agent required running repeated episodes in the TreasureMaze environment. During each episode, the agent made decisions, received feedback, and updated its learned information.

I monitored training information such as the number of episodes, loss, win count, and win rate. This allowed me to evaluate whether the agent was learning and whether changes to the training process affected its performance.

The training process also showed me that machine learning algorithms do not always produce the expected result on the first attempt. I encountered situations where the training results did not reach the expected outcome. Instead of assuming the code was correct because it ran, I examined the results and used them to evaluate the behavior of the agent.

PROBLEM SOLVING

Challenges and Improvements

One of the most challenging parts of this project was understanding why the agent's training results did not always behave as expected. Training an AI agent involves many interacting factors, including the reward structure, exploration rate, learning rate, number of training episodes, and the representation of the environment.

I learned to approach these problems systematically by examining the code, reviewing error messages and warnings, monitoring training output, and making controlled changes to the training process.

This experience strengthened my ability to troubleshoot algorithms instead of relying only on whether a program successfully executed.

ARTIFACT NARRATIVE

Learning and Reflection

The TreasureMaze project helped me understand algorithms in a more practical way. Instead of implementing an algorithm only to produce a specific output, I had to consider how an algorithm could allow an agent to make decisions and improve through experience.

Working with reinforcement learning also showed me how important experimentation is in artificial intelligence. Small changes to training parameters or the learning environment can affect the behavior of the agent. I had to evaluate results rather than assuming that the first training run represented the final performance of the system.

The project also improved my understanding of the relationship between algorithms and data structures. The algorithm determines how the agent processes information and makes decisions, while the underlying data structures provide a way to represent and organize the information needed by the algorithm.

Overall, TreasureMaze demonstrates my growth in algorithmic thinking, artificial intelligence, debugging, and technical problem solving.
