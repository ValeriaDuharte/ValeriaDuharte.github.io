EXISTING FUNCTIONALITY

Artifact Review

My code review focused primarily on the Travlr Getaways application and the TreasureMaze/Pirate Intelligent Agent. These projects were selected because together they demonstrate different areas of my development throughout the Computer Science program.

The Travlr application is a full-stack web application that uses Angular for the frontend, Node.js and Express for the backend, and MongoDB for data storage. The application allows travel information to be retrieved and displayed through communication between the frontend, backend API, and database.

The TreasureMaze project uses a reinforcement-learning intelligent agent to navigate a maze and find treasure. The agent uses states, actions, rewards, experience replay, and deep Q-learning to learn an effective path through the environment.

CODE ANALYSIS

Areas Identified for Improvement

Reviewing the existing projects allowed me to identify areas where the original implementations could be strengthened. For Travlr, I focused on software organization, reliability, error handling, database communication, validation, and maintainability.

The application contained several interacting components, which meant that problems in one layer could affect another. I therefore planned enhancements that would improve the reliability of communication among the Angular frontend, Express API, and MongoDB database.

For TreasureMaze, I focused on the effectiveness of the reinforcement-learning solution and how its results were evaluated. The training process required attention to exploration and exploitation, experience replay, training stability, and meaningful performance measurements.
